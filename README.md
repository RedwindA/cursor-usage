# Cursor 用量明细

在 Cursor 网页右下角显示个人订阅花了多少钱。官方只给百分比，这个扩展补上美元数字。

数据只在你已登录的 Cursor 页面里读，不会上传。

目前只支持个人套餐（Pro / Pro+ / Ultra）。

## 怎么用

已经打好包，不用再跑命令。

1. Chrome 或 Edge 打开扩展页  
   - Chrome：`chrome://extensions`  
   - Edge：`edge://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选本仓库里的 **`extension`** 文件夹（不要选上一级）
5. 登录打开 [cursor.com/dashboard](https://cursor.com/dashboard)

浮层会出现在右下角。

| 操作 | 说明 |
|---|---|
| 拖标题栏 | 挪位置（会记住） |
| 收起 | 缩成两条摘要，并回到右下角 |
| 放大 | 一屏显示全部内容，再点还原 |
| 回到右下角 | 展开时一键复位 |
| 刷新 | 立刻重新拉数 |
| 设置 | 选多久内再进页面不自动刷新，默认 1 分钟 |
| 关闭 | 收成右下角「用量」按钮。刷新页面会重新展开；点该按钮或工具栏图标也能再打开 |

改过源码后，在本目录执行 `npm run build`，再到扩展页点刷新。

## 数字怎么来的

官方月度用量分两个池子。Grok Bot 另有周限额，不进官方 Other。

两个月度池的总额都用同一套反推，不写死套餐额度，也不用 `plan.used / plan.limit`（那是 included 计量，会先顶到 API 上限）。

> 总额 ≈ round(该池累计模型用量 ÷ 官方百分比, 10)

已用金额：把账单里该池模型的费用加起来。Grok Bot 不进第三方池。  
百分比：页面上的官方进度（第一方 `autoPercentUsed`，第三方 `apiPercentUsed`）。

反推成功后会记住。本周期该池用量为 0、或进度已满无法反推时：

- 有历史估算 → 沿用，并提示
- 没有历史（首次使用）→ 标明当前无法推断总额

这不是 Cursor 官方标称额度。

### Other Models（第三方，如 Claude、GPT）

例如：第三方账单 **$72.40**，进度 **18.1%**  
→ `72.40 ÷ 18.1% ≈ $400` → **$72.40 / $400**

### Cursor Models（第一方，Composer、Cursor Grok）

例如：花了 **$864.53**，进度 **28.815%**  
→ `864.53 ÷ 28.815% ≈ $3000.29` → **$3000**

### Grok Bot（独立周限额）

Grok Bot 不进官方 Other。周进度来自 `get-sand-usage-status` 的 `usagePercent`，接口同样不给美元上限。

反推方式和第一方相同，用**本周** Bot 账单 ÷ 官方周进度，再按 **$10** 取整。本周用量为 0 或进度已满时：有历史就沿用并提示，没有就标明无法推断。卡片上的「本周期账单」仍是月度合计，和周限额不是同一窗口。

点卡片或标签可以只看这类模型。

## 注意

- 第一方、第三方和 Grok Bot 总额是估算，可能和真实池子有偏差
- 自动刷新默认只在 `cursor.com/dashboard` 这一页发生，进 Settings 等子页面不会重拉
- 团队账号暂不支持
